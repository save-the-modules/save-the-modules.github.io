# 데이터 출처와 적용 범위

## v2.3 확인 사항 (2026-10-17)

이번 작업에서 사용자가 직접 설명한 규칙: 슬롯 등장 100/50/30%, 2번이 비어도 3번 등장 가능, 9종 중 같은 장비 내 종류 중복 불가, 잠금의 종류·수치 보존, 전체 결과 적용/취소, 취소 시 모듈 미환급, 9월 패치 이후 새 잠금 재료는 리롤 실행 때 소비, 영구 잠금은 결과 취소 후에도 유지되는 것으로 파악, 동일 종류·동일 수치 재추첨 방지(빈 슬롯 예외).

사용자가 공식 확인하지 않은 사항: 게임 내부 추첨 순서, 슬롯 등장 여부의 독립성, 중복 제외 후 확률 재정규화. v2.3은 **독립 등장 + 잠긴 종류 우선 제외 + 슬롯 순서 1→2→3 + 남은 종류 가중치 재정규화**를 명시적 가정으로 사용한다. 현재 단계 제외 후 단계 가중치 재정규화 및 슬롯별 수치 독립성도 모델 가정이다. 공개된 공식 원문은 확보하지 못했다. 기존 사용자 교정 표는 유지한다.

아래 v2.2 기록의 ‘조건부 경로 제외’는 과거 엔진의 범위다. v2.3에서는 가정을 화면에 표시하고 해당 경로를 계산한다. 외부 계산기의 공개 설명도 같은 가정을 적고 있지만 게임사의 공식 인증으로 취급하지 않는다. [설계·한계](ENGINE.md)를 함께 확인한다.
