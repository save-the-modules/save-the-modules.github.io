# STM v2.3.1 계산 구조

## v2.3.1 추가: 실제 합계와 수치 재설정

이 문서 아래의 v2.3 해석적 모델은 비교 기준과 대체 경로로 남아 있습니다. v2.3.1은 `sumPolicy.ts` / `sumEstimate.ts`의 제한된 실행 정책도 평가합니다. 상세한 동일 조건 비교·한계는 [SUM-AUDIT.md](SUM-AUDIT.md)를 참고하세요.

1. 특정 옵션 1–3종은 가능한 종류 배치를 모두 생성합니다(최대 216개). 합계 목표는 백분율의 1/100 단위 정수로 취급하며 소수 둘째 자리보다 정밀한 목표는 올림합니다. 종료는 실제 전체 줄 수와 실제 합계로 판정합니다.
2. 고정 배치와 결과별 배치 재선택 정책을 비교합니다. 배치 휴리스틱은 확보 종류 수, 수치, 균형 순으로 점수를 부여합니다. 이는 비용 최적 배치 증명이 아닙니다. 새 잠금 이후에도 배치의 용량 제한을 다시 검사합니다.
3. 부위별 8단계를 강제하지 않고, 현재 높은 값과 이미 잠긴 값을 공제한 잔여 합계를 나머지 배정 줄에 균등 분담합니다. 목표를 초과한 기존 값은 크레딧입니다. 배정 밖 줄은 진행 평가에서 제외하지만, 실제 전체 목표를 달성하면 즉시 종료합니다.
4. 낮은 단계의 목표 종류를 채용하고, 동반 종류를 찾기 전에 수치 재설정으로 부족분을 보완할 수 있습니다. 현재 분담량을 충족한 줄만 새로 잠그고, 종류가 부족한 부위부터 작업합니다. 기존 잠금은 해제하지 않습니다.
5. 전체 결과 채용 시 배정 종류별 확보 줄 수와 목표까지의 합계가 감소하지 않아야 하며, 배정 줄 수 또는 합계 점수가 엄격히 증가해야 합니다. 이미 전체 목표를 달성한 결과는 채용합니다. 실패 결과를 취소해도 실행 비용과 새 잠금은 남습니다.
6. 각 후보 128회 예비 표본으로 비교한 뒤 선택 정책을 다른 시드의 2,048회 표본으로 평가합니다. 기존 해석적 비용보다 평균+3표준오차가 낮을 때만 새 정책을 표시합니다. 이는 통계적 선택 기준이지 최적성 증명이 아닙니다.
7. 한 경로 20,000모듈, 예비 후보별 총 80,000회/검증 총 800,000회 실행 한도입니다. 미완료가 하나라도 있으면 유한 평균으로 채택하지 않습니다. 희귀 목표는 기존 모델로 돌아갑니다. 표본 오차와 미검증 모델 오차는 별개입니다.
8. 평균은 완료 비용의 산술평균, 예산 확률은 같은 표본의 경험 CDF입니다. 평균의 근사 95% 오차와 CDF의 Wilson 95% 구간을 표시합니다. 전부 성공/실패한 표본도 보장/불가능 판정이 아닙니다. 예산만 바뀌면 표본 재추출 없이 CDF만 갱신합니다.

장비를 다시 입력하면 종류 배치와 정책을 다시 선택하므로 표시한 고정 정책의 기대값과 실제 재계산을 반복하는 사용 경험이 완전히 같지는 않습니다. 자동 재계산은 기존 Worker 취소·캐시·저장 구조를 유지합니다. 베이킹 파일은 없으며 비용 표본은 목표당 2,048개입니다.

## 이하: v2.3 해석적 대체 경로

## 선택한 구조

전체 장비 12슬롯 × 9종 × 15단계 × 잠금 상태를 직접 전역 MDP로 풀면 브라우저용으로 지나치게 커진다. 이 대체 경로는 **배분 탐색 + 제한된 부위별 정책 DP + 예산 DP**를 사용한다. 이 경로 자체의 몬테카를로는 독립 검증용으로 쓴다.

1. 목표 종류를 4부위에 배분한다. 각 장비는 동일 종류를 중복 배정할 수 없고 최대 3줄이다. 크크 줄은 크확/크뎀 중 하나에 독점 배정한다.
2. 균등 단계 배분으로 각 배치를 평가한다. 최소 단계 비용으로 순위를 매긴 최대 32개 배치와 균등 배분의 최선 배치를 대상으로 현재 수치를 출발점으로 부족 합계를 보충한다. 매 단계 증가의 예상 비용이 가장 작은 후보를 선택한다. 이는 완전한 수치 조합 탐색이 아니다.
3. 부위별로 현재 목표에 관련된 옵션 종류와 현재 수치를 보존 조건에 추가한다. 이미 달성한 부위는 비용 0이다.
4. 모든 합법적 기존/추가 잠금 마스크(최대 2줄)에 대해 효과 변경과 수치 재설정의 일괄 달성 확률을 계산한다. 각 정책은 불합격 결과를 거절한다.
5. 기준 이상 옵션을 얻은 중간 결과를 채용하고 다음 실행 때 잠그는 단조로운 획득 정책을 함께 평가한다. 더 싼 정책을 선택한다.
6. 부위 비용을 합산해 배분을 선택한다. 다음 행동은 미완료 부위 중 잔여 비용이 가장 낮은 부위다. 같은 고정 배분을 끝낼 때의 총비용 분포는 부위 작업 순서에 영향받지 않는다.

베이킹 파일은 없다. 부위 평가 메모는 계산 1회 동안만 유지하고 49,000항목에서 오래된 항목을 내보낸다. 배분 100,000개 제한은 결과에 명시한다. 대표 12줄 정책의 전체 전이 노드는 112개다.

## 확률 커널

`rules.ts`는 잠금 종류를 먼저 제외하고 슬롯 1→2→3 순서로 종류를 비복원 가중추첨한다고 가정한다. 등장 여부는 100/50/30% 독립이며, 없는 2번 슬롯은 3번 슬롯을 막지 않는다. 효과 변경에서 현재와 같은 종류가 같은 슬롯에 등장하면 그 슬롯의 이전 단계를 제외한다. 수치 재설정은 종류/슬롯 유무를 유지하고 잠기지 않은 슬롯만 수치를 재추첨한다.

종류별 가능한 결과를 열거하고 조건을 만족할 수치 확률을 곱한다. 비목표 종류도 중복 배제 분모에 영향을 주므로 개별 종류를 열거하며 단순히 하나의 기타 종류로 합치지 않는다. 이미 만족한 잠긴 요구는 남은 추첨에서 제거한다.

## 획득 DP의 정확한 범위

상태는 기준 이상으로 확보한 종류의 슬롯 위치와 기존 잠금이다. 이미 확보한 옵션은 이후 반드시 잠그며 목표 수치가 더 낮아지지 않는다. 아래 조건에서만 새 결과를 채용한다.

- 하나 이상의 추가 목표 옵션이 기준 이상으로 등장한다.
- 기준 미달의 목표 종류가 결과에 섞이지 않는다.
- 원래 있던 유효 옵션을 잃거나 그 수치를 줄이지 않는다.

새로 잠글 옵션의 실제 초과 단계는 이후 추첨에 영향을 주지 않는다. 미확보 슬롯에는 목표 외 종류 또는 빈 슬롯만 남으므로 이후 목표 수치의 이전 단계 제외 효과도 없다. 따라서 목표 외 옵션의 실제 단계와 현재 종류를 상태에 저장하지 않아도 해당 정책의 미래 목표 획득 확률은 정확히 보존된다. 시작 장비의 실제 옵션/단계는 첫 상태의 추첨에 반영한다. 비목표 종류는 **새 추첨 내부**에서는 여전히 개별적으로 열거한다.

새 성공이 없는 결과, 낮은 목표 단계가 포함된 결과, 기존 유효 옵션이 사라진 결과는 기존 상태로 돌아간다. 새 잠금 비용은 다음 리롤 때 지불하므로 완료 상태에는 추가 잠금 비용이 없다. 상태 그래프는 확보한 옵션 수가 증가하는 DAG이며 거절 자체 순환만 있다.

상태 s의 반복 비용 c, 진전 전이 확률 pᵢ, 자식 기대비용 Eᵢ, 전이 후 새 잠금 비용 lᵢ에 대해:

`E(s) = (c + Σ pᵢ × (lᵢ + Eᵢ)) / Σ pᵢ`

첫 상태의 새 잠금 비용은 한 번만 더한다. 이 값은 **정해진 단조로운 정책의 기대값**이다. 각 상태에서 모든 효과/수치/해제/수락 전략을 최적화한 Bellman 최적값은 아니다. 기존 수치 개선은 일괄 수치 재설정 후보로 비교한다.

## 예산 확률

`F(s,b) = (1−Σpᵢ) F(s,b−c) + Σpᵢ F(childᵢ,b−c−lᵢ)`

종료 상태는 b≥0이면 1, b<0이면 0이다. 4부위 정책의 종료 전이를 다음 부위 시작으로 연결한다. 기대값만으로 분포를 추정하지 않는다. 회당 비용과 잠금 비용의 최대 지연만 저장하는 원형 버퍼를 써서 메모리는 예산과 무관하다. 확률이 1에서 1e-12 이내일 때만 조기 100% 처리한다. 오래 걸리는 희귀 목표의 작은 성공확률을 임의의 확률 바닥이나 꼬리 재정규화로 바꾸지 않는다.

## 한계

이 모델은 공식 내부 추첨 규칙의 인증이 아니다. 슬롯 독립성, 추첨 순서, 비복원 가중치 재정규화, 수치 제외 후 재정규화는 가정이다. `DrawOrder`로 역순 민감도 검사를 지원한다. 순서를 바꿔 결과가 비슷하더라도 나머지 가정까지 검증되는 것은 아니다.

수치 배분 후보 제한, 유효 옵션의 강한 보존 제약, 기준 미달 결과 거절, 잠금 해제·임시 잠금권 제외 때문에 게임의 최적 전략보다 비쌀 수 있다. 표시된 비용은 **가정된 확률 모델에서 실행 가능한 정책의 비용**이며 실제 게임 최적 비용의 수학적 상한이라는 주장은 하지 않는다. 예산 확률을 최대화하는 별도 정책도 탐색하지 않는다.

실제 결과를 입력하면 배분을 새로 계산한다. 이 재계산은 초과 수치와 예기치 않은 유효 옵션을 활용하지만, 그 이득이 최초 비용/확률에 모두 선반영되는 것은 아니다.
