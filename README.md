# Save the Modules (STM) · UI v2.0

승리의 여신: 니케의 오버로드 장비 입력과 목표 관리를 위한 비공식 웹 앱입니다. React 19, TypeScript, Vite, Tailwind CSS 4, Lucide를 사용합니다. 서버나 계정 없이 동작합니다.

## 실행

Node.js 22 이상 권장.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

빌드 결과는 `dist/`입니다. `file://` 대신 정적 HTTP 서버로 열어 주세요.

## 기능

- 4부위 × 3슬롯 인라인 편집, 옵션·티어·직접 수치·잠금, 합산 수치
- 데스크톱 sticky 패널, 모바일 접이식 패널과 상단 요약
- 독립적인 최소/타협/종결 목표, 이전 단계 복사, 줄 수·합계·줄별 하한
- 크확/크뎀/크크의 중복 없는 결정적 충족 판정, 2.88 환산
- 보유량 이하 모듈 예산, 안정형 90% / 도전형 50%
- 가이드 단계 수동 선택, 리롤 기존/신규 비교·채용·거절
- 분리된 데모와 데모 종료 시 사용자 데이터 복구
- localStorage 자동 저장, 스키마 v2 JSON 입출력, 구분된 초기화
- 잘못된 JSON 거절, 손상된 저장 데이터 자동 덮어쓰기 방지

## 티어 데이터

`src/data/tiers.ts`의 `VERIFIED_TIERS`는 의도적으로 비어 있습니다. 검증하지 않은 게임 수치를 제공하지 않습니다. 실제 모드에서는 티어를 선택해도 미등록 수치를 자동 생성하지 않으며 수치를 직접 입력해야 합니다. 검증된 데이터가 생기면 옵션 ID별 T1~T15 배열을 등록하세요. 데모 수치는 별도 가상 데이터입니다.

평균 티어는 합계 입력을 돕는 선택입니다. 독립적인 평균 티어 충족 조건은 아닙니다. 줄별 최소 티어를 조건으로 사용하세요. 하한은 목표 줄의 순서와 무관하게 정렬해 배정됩니다. 지정된 줄 수만큼 선택한 옵션들의 합계와 하한을 평가합니다. 빈 목표는 달성 완료로 처리하지 않습니다. 12줄을 넘긴 목표는 오류 상태로 저장되므로 수정 후 이어서 사용할 수 있지만, 잘못된 목표를 가진 외부 JSON은 불러올 수 없습니다.

크크 목표는 크뎀 수치를 2.88로 나눠 크확 기준으로 비교합니다. 전투 피해 효율 동등성을 뜻하지 않습니다. 같은 티어의 환산 등급은 동일하게 처리하되 직접 입력 수치는 입력값을 그대로 환산합니다.

## 계산 엔진 연결

`src/model.ts`에 `EngineInput`, `EngineResult`, `toEngineInput`을 정의했습니다. 확률·기대 비용·잠금 전략·DPS 엔진은 구현하지 않았습니다. 실제 모드 가이드는 계산 전 상태이며 추천을 생성하지 않습니다.

엔진 연결 시 입력이 바뀔 때마다 결과를 무효화하고 `toEngineInput(state)`를 전달하세요. 결과의 `source`는 `engine` 또는 `demo`입니다. `recommend`는 반환된 확률과 투자 성향 기준만 비교합니다. 기준 미달이면 null입니다. UI의 `result` 공급 지점에 입력과 일치하는 엔진 결과를 연결할 수 있습니다. 리롤 변경 시에도 새 입력으로 재계산하세요.

데모 성공 확률은 예산 구간 0~19 / 20~59 / 60~119 / 120 이상에 대응하는 고정 시나리오입니다. 데모 비용·추천은 장비 편집에 따른 확률 재계산이 아닙니다. 사용자 저장 키 `stm-state-v2`에는 데모를 기록하지 않습니다. 데모 중 내보내기·불러오기·초기화는 데모에만 적용됩니다.

## GitHub Pages

이 폴더의 내용을 저장소 루트로 업로드하세요. GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택하고 `main`에 push하면 `.github/workflows/deploy.yml`이 테스트·빌드 후 배포합니다. 상대 경로 `base: './'`를 사용하므로 프로젝트 하위 경로에서 작동합니다. 새로고침 경로 문제가 없는 단일 페이지 구조입니다.

제공 환경에서는 GitHub 저장소 연결이나 실제 배포 권한이 지정되지 않았으므로 원격 배포는 실행하지 않습니다. 로컬 빌드 및 배포용 파일을 제공합니다. 저장소를 만들 때 `node_modules/`와 `dist/`를 커밋하지 마세요.

## 저장과 복구

개인 데이터는 이 브라우저·이 출처에만 저장됩니다. 다른 기기/브라우저/배포 주소 사이에는 JSON으로 이동하세요. 저장 실패 시 알림이 유지되며 내보내기를 사용할 수 있습니다. 손상된 저장 데이터 발견 시 자동 저장을 중지합니다. 유효한 JSON 불러오기 또는 전체 초기화로 복구합니다. 전체 초기화 시 기존 손상 문자열은 가능하면 `stm-invalid-state-backup` 키로 보관합니다.
